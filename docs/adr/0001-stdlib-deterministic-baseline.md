# ADR-0001：使用标准库建立确定性单内核基线

- 状态：Accepted
- 日期：2026-08-07

## 背景

BraveNewWorld 需要尽快成为具有教学价值、可交互、可无头验证的真实 JobSlayer 测试床。首个基线还没有证明需要前端框架、数值库或服务基础设施。

## 决策

BNW-0 使用 Python 3.11+ 标准库实现契约、确定性仿真、loopback HTTP API 和测试；使用原生 HTML/CSS/JavaScript Canvas 实现模块化 UI。交互与 CLI 必须调用同一 Python 仿真函数。首个一阶系统使用精确离散更新，不因教学用步长引入欧拉积分误差。

## 后果

- 空仓库可以零运行时依赖启动和测试，基线容易固定与复现。
- UI 仍与仿真核分离，未来可以替换绘图库或应用壳。
- 当前图表和状态管理能力刻意有限；当至少两个主题证明公共交互或绘图需求后，再评估引入依赖。
- 新依赖必须有具体功能需求、替代方案比较和退出条件记录。
